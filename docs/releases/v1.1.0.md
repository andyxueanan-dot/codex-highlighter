# Codex Highlighter v1.1.0

The first packaged Windows release of Codex Highlighter.

## Highlights

- persistent five-color highlighting in the main transcript and side chat;
- compact palette that avoids Codex's native selection menu;
- direct hover deletion and selection-based recoloring;
- local text/context/position anchors with automatic re-anchoring;
- native tray data manager with search, delete, clear, JSON import and export;
- current-user installer and data-preserving uninstaller;
- loopback-only CDP connection, renderer health checks and bounded log rotation.

## Install

1. Download `codex-highlighter-v1.1.0-windows-x64.zip` and its `.sha256` file.
2. Verify the archive if desired:

   ```powershell
   Get-FileHash .\codex-highlighter-v1.1.0-windows-x64.zip -Algorithm SHA256
   ```

3. Extract the archive.
4. Run `install.ps1` in PowerShell.
5. Approve the one-time Codex restart.

The installer writes only to the current user's `%LOCALAPPDATA%` and Start menu. It does not require administrator privileges.

## Compatibility

Verified on Windows 11 Pro x64 build 26200 with Codex Desktop `26.818.5229.0` and Chromium `151.0.7922.170`. See the full [compatibility matrix](https://github.com/andyxueanan-dot/codex-highlighter/blob/main/docs/COMPATIBILITY.md).

## Security note

Codex is launched with an unauthenticated debugging endpoint restricted to `127.0.0.1`. Other processes under the same Windows account are inside that trust boundary. See [SECURITY.md](https://github.com/andyxueanan-dot/codex-highlighter/blob/main/SECURITY.md) before use on a shared machine.

The executable is not commercially code-signed, so Windows may show a reputation warning for the first run.
