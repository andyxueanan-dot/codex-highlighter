# Codex Highlighter v1.2.2

This patch adds highlighting support for Codex plain-text and code cards.

## Added

- Plain-text content inside clickable Codex cards can now be highlighted.
- `pre`, `code`, `samp`, `kbd`, and `tt` are recognized as literal-text regions.
- Syntax-highlighted code selections may span multiple nested `span` nodes.
- The enclosing `pre` block is used as the persistent anchor when available.

## Safety boundary

Actual buttons, menu controls, text inputs, content-editable regions, Lexical editors, and `role=textbox` composers remain excluded. A clickable card wrapper is bypassed only when both ends of the selection are inside literal text.

The browser regression verifies persistent highlights in a `pre > code` plain-text card and in multi-span syntax-highlighted code, while confirming that a real button and composer do not open the palette.

## Install or update

1. Download `codex-highlighter-v1.2.2-windows-x64.zip` and its `.sha256` file.
2. Extract the archive and run `install.ps1`.
3. Existing highlights and startup recovery settings are preserved.

The executable is not commercially code-signed, so Windows may show a reputation warning for the first run.
