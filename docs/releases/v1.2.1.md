# Codex Highlighter v1.2.1

This patch removes the delay before the color palette appears in heavily highlighted conversations.

## Fixed

- The palette is displayed first; existing-highlight recognition runs on the next animation frame.
- Selection no longer scans every resolved highlight across the full transcript.
- Stale virtualized Ranges no longer trigger a synchronous full re-anchor before the palette is shown.
- Delete and recolor detection use the selected scope hash, message identity, surrounding context, and offsets.
- Native Codex menu avoidance is applied asynchronously after initial display.

The regression test creates 120 resolved highlights, removes their DOM nodes, then requires a new palette to appear in under 100 ms without incrementing the re-anchor count.

On the verified Codex installation, the real-app palette appeared in 5.2 ms with 173 stored highlights and did not increment the re-anchor count. This is an environment-specific measurement rather than a universal guarantee.

## Install or update

1. Download `codex-highlighter-v1.2.1-windows-x64.zip` and its `.sha256` file.
2. Extract the archive and run `install.ps1`.
3. Existing highlights and startup recovery settings are preserved.

The executable is not commercially code-signed, so Windows may show a reputation warning for the first run.
