# Codex Highlighter v1.2.6

This release adds persistent highlighting for mathematical formulas rendered by KaTeX.

## Added

- Display and inline KaTeX formula selections.
- Partial selections spanning multiple visible formula nodes.
- Stable formula identities using response/message context, formula position, and a TeX fingerprint.
- Hidden MathML selection normalization to the visible formula when necessary.
- CSS grid/div table selections when Codex renders a table without native table or ARIA semantics.

## Fixed

KaTeX renders each formula more than once: a clipped MathML accessibility tree, a TeX annotation, and the visible `.katex-html` layout. Previous versions saved the selection against a generic container and could not resolve it back to the visible formula. v1.2.6 uses the formula itself as the scope and calculates offsets only from its visible layer.

The regression suite verifies that the CSS highlight range stays inside `.katex-html` and returns to the original formula after complete DOM replacement. It also verifies a `div`-based “part of speech / meaning” table after the entire CSS grid is replaced.

## Install or update

1. Download `codex-highlighter-v1.2.6-windows-x64.zip` and its `.sha256` file.
2. Extract the archive and run `install.ps1`.
3. Existing local highlight data is retained.

The executable is not commercially code-signed, so Windows may show a reputation warning for the first run.
