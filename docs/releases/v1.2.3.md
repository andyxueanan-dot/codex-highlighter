# Codex Highlighter v1.2.3

This patch adds highlighting support for Codex tables.

## Added

- Native `table`, `thead`, `tbody`, `tfoot`, `tr`, `th`, and `td` content.
- ARIA `table`, `grid`, `row`, `cell`, `gridcell`, `columnheader`, and `rowheader` content.
- Selections spanning nested formatting nodes inside a cell.
- Stable identities containing table, row, and cell indexes.

Single-cell selections use the cell itself as the persistent scope. Wider selections are promoted to their common row or table. Repeated values such as multiple `0.1` cells remain bound to the originally selected coordinates after the table is re-rendered.

## Safety boundary

Clickable table cards are allowed only when both ends of the selection belong to the same table/grid. Actual copy buttons, menu controls, text inputs, content-editable regions, Lexical editors, and `role=textbox` composers remain excluded.

## Install or update

1. Download `codex-highlighter-v1.2.3-windows-x64.zip` and its `.sha256` file.
2. Extract the archive and run `install.ps1`.
3. Existing highlights and startup recovery settings are preserved.

The executable is not commercially code-signed, so Windows may show a reputation warning for the first run.
