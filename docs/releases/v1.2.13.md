# v1.2.13 — Smoother highlighting and reliable window activation

## Performance

- Reuse cached text scopes and rebuild affected regions after changes.
- Split re-anchoring into short cooperative tasks instead of one long synchronous pass.
- Avoid timer throttling in background windows and repaint starvation during continuous status updates.
- Remove selection queries from pointer-move callbacks and cache hover geometry.

The regression fixture uses 1,374 saved records and 900 text scopes. A local edit rebuilds 9 scopes and reuses 891. Observed local-update runs were approximately 30–52 ms on the development machine; these are fixture measurements, not a latency guarantee for every conversation or computer.

## Windows launcher

Includes the launcher changes developed in v1.2.12: focus the app before connection probes, use the Windows Store application identity, handle foreground permissions, and report unconfirmed launches. Opening the shortcut never forcibly exits or automatically restarts an existing Codex process.

## Validation and data safety

The full native, installer, browser, math, retention, and large-transfer suites pass. Additional tests cover cache invalidation, continuous updates, pointer storms, cleanup, and background timer clamping. Existing highlight records and retention behavior are preserved.

Download and extract the Windows ZIP, then run `install.ps1` to update. Saved highlights are retained. If Codex already exposes the local debugging connection, the helper can reconnect without restarting Codex; otherwise, save your work and use the combined shortcut after a normal exit.
