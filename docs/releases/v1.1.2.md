# Codex Highlighter v1.1.2

This release makes highlighting survive Windows sign-in and independent Codex restarts.

## Fixed

- The tray host now starts automatically for the current Windows user after installation.
- Startup mode waits quietly while Codex is closed and does not launch it during sign-in.
- Opening or restarting Codex without the debugging flags triggers automatic recovery after three confirmed endpoint failures.
- Repeated endpoint timeouts are rate-limited in the log.
- Uninstall removes the Start menu and startup shortcuts while preserving highlight data by default.

## Install or update

1. Download `codex-highlighter-v1.1.2-windows-x64.zip` and its `.sha256` file.
2. Extract the archive and run `install.ps1`.
3. Existing highlight data is preserved.

Verified on Windows 11 Pro x64 build 26200 with Codex Desktop `26.818.5229.0` and Chromium `151.0.7922.170`. See the [compatibility matrix](https://github.com/andyxueanan-dot/codex-highlighter/blob/main/docs/COMPATIBILITY.md).

The executable is not commercially code-signed, so Windows may show a reputation warning for the first run.
