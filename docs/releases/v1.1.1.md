# Codex Highlighter v1.1.1

This patch release fixes short-word anchors that could move to later duplicate text.

## Fixed

- A highlight on a short word such as “four” or “四个” now remains attached only to the originally selected occurrence.
- Later duplicate words in transcript messages or the composer no longer inherit that highlight.
- If the original message is temporarily removed from the DOM, the highlight becomes unresolved instead of moving elsewhere.
- When the original message returns, whitespace-only layout differences do not prevent restoration.
- Editable text boxes, content-editable regions, Lexical editors, and `role=textbox` surfaces are excluded from restoration candidates.

## Install

1. Download `codex-highlighter-v1.1.1-windows-x64.zip` and its `.sha256` file.
2. Extract the archive and run `install.ps1`.
3. Existing highlight data is preserved automatically.

Verified on Windows 11 Pro x64 build 26200 with Codex Desktop `26.818.5229.0` and Chromium `151.0.7922.170`. See the [compatibility matrix](https://github.com/andyxueanan-dot/codex-highlighter/blob/main/docs/COMPATIBILITY.md).

The executable is not commercially code-signed, so Windows may show a reputation warning for the first run.
