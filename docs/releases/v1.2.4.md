# Codex Highlighter v1.2.4

This stability patch keeps the tray monitor independent from the process that installs or starts it.

## Fixed

- The installer now launches Codex Highlighter through the Windows process service, with a desktop-shell fallback, instead of as a direct child of the terminal or Codex task that ran the installer.
- Switching Codex accounts can restart the Codex process tree without taking the tray monitor down with it.
- The surviving monitor continues to detect a missing loopback debugging endpoint, restore it, and reinject the highlighter.
- Application start and clean exit events are now recorded in `CodexHighlighter.log` for clearer lifecycle diagnostics.

Existing highlights, color choices, data-manager contents, and startup recovery settings are preserved during the update.

## Install or update

1. Download `codex-highlighter-v1.2.4-windows-x64.zip` and its `.sha256` file.
2. Extract the archive and run `install.ps1`.
3. Existing local highlight data is retained.

The executable is not commercially code-signed, so Windows may show a reputation warning for the first run.
