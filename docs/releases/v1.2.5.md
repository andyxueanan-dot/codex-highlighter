# Codex Highlighter v1.2.5

This safety patch puts Codex's native behavior ahead of automatic highlight recovery.

## Fixed

- Removed all background code that could close or relaunch Codex after a temporary debugging timeout or disconnect.
- Background monitoring now retries only; it cannot terminate the Codex process.
- Restarting Codex for a manual reconnect requires choosing the tray command and approving the confirmation dialog.
- Clicking Add to conversation, Ask in side chat, or More immediately dismisses the highlight palette and passes the native action through without recapturing the selection.
- Added regression checks for native side-chat actions and non-destructive monitor failures.

## Important behavior change

If Codex is manually opened without the loopback debugging port, highlighting stays inactive rather than forcing a second restart. Use **Connect or restart Codex (confirmation required)** from the yellow tray icon when you want to restore highlighting.

Existing local highlight data is preserved during the update.

## Install or update

1. Download `codex-highlighter-v1.2.5-windows-x64.zip` and its `.sha256` file.
2. Extract the archive and run `install.ps1`.
3. Existing local highlight data is retained.

The executable is not commercially code-signed, so Windows may show a reputation warning for the first run.
