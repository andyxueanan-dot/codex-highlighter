# Codex Highlighter v1.2.7

This patch fixes “ghost highlight” selection states.

## Fixed

- The color palette no longer shows the delete button merely because stale anchor metadata overlaps the selected offsets.
- Unresolved or disconnected anchors cannot block adding a new visible highlight.
- Recolor and delete now require a live CSS Highlight Range whose connected DOM boundaries truly intersect the current selection.
- Adjacent text remains independent, while selecting a real visible highlight still exposes recolor and delete.

The regression suite includes an unresolved anchor with the same response identity and overlapping offsets as the current selection. v1.2.7 verifies that it stays invisible, does not expose delete, and does not prevent a new highlight from being created.

This release also includes the v1.2.6 KaTeX formula and CSS grid/div table support.

## Install or update

1. Download `codex-highlighter-v1.2.7-windows-x64.zip` and its `.sha256` file.
2. Extract the archive and run `install.ps1`.
3. Existing local highlight data is retained.

The executable is not commercially code-signed, so Windows may show a reputation warning for the first run.
