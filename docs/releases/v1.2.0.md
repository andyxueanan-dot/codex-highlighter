# Codex Highlighter v1.2.0

This release focuses on responsiveness in long Codex conversations.

## Performance changes

- Healthy monitoring runs every 15 seconds instead of every 1.8 seconds.
- Renderer metadata is checked in one lightweight call, and JSON moves only when its revision changed.
- The avatar overlay is no longer injected or synchronized.
- DOM observation is limited to transcript surfaces and streaming updates are coalesced for one second.
- Anchor lookup uses scope hashes and message identities before any contextual fallback.
- Expensive fallback matching is limited to initial loading and anchors already visible on screen.
- Re-anchoring runs during browser idle time and no longer blocks ordinary text selection.
- Hover hit-testing is throttled.

The browser regression loads 600 historical anchors, applies 25 consecutive DOM mutations, and requires a single indexed re-anchor pass with no historical fallback scans.

## Measured result

On Windows 11 build 26200 with 175 stored highlights and Codex Desktop `26.820.9563.0`:

- the tray host fell from about 5.3% of one CPU core to 0.21% in a 30-second sample;
- Codex root + renderer CPU fell from about 9.4% to 4.68%;
- 23 observed streaming mutation batches were coalesced into one 36.4 ms indexed pass with zero historical fallback anchors;
- the avatar overlay contained no injected runtime.

These figures are environment-specific measurements rather than universal guarantees.

## Install or update

1. Download `codex-highlighter-v1.2.0-windows-x64.zip` and its `.sha256` file.
2. Extract the archive and run `install.ps1`.
3. Existing highlight data and startup recovery settings are preserved.

The executable is not commercially code-signed, so Windows may show a reputation warning for the first run.
