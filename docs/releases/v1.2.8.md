# Codex Highlighter v1.2.8

Use the new **Codex（带高亮）** desktop or Start menu shortcut to start Codex with highlighting from the first launch. This avoids the usual open-Codex-then-restart sequence.

- Closed Codex: starts with a loopback debugging port and begins watching for the renderer.
- Existing Codex with an endpoint: reconnects and brings the current window forward.
- Existing Codex without an endpoint: preserves the window and waits. Use the combined shortcut after your next normal exit.
- Tray monitor already running: repeated shortcut launches signal that monitor instead of creating duplicates or showing an “already running” dialog.
- Background startup remains passive. Even explicit reconnects no longer force-kill Codex if graceful exit fails.

The shortcut resolves the current installed application on every launch, avoiding a hardcoded Store version. Existing highlights and original Codex shortcuts are preserved. Desktop shortcut creation can be disabled with `install.ps1 -NoDesktopShortcut`.

Validation includes simulated cold/repeated opens, existing windows with and without ports, changed ports, named launch signaling, real windowless process detection, loopback endpoint identity, and install/update/uninstall shortcut handling. A real cold launch is not forced during an active Codex session.

Live validation on Codex 26.901.5280.0: repeated opens reused both the existing Codex window and tray monitor, v1.2.8 injected successfully, and all pre-update highlight IDs were retained. Updating a running executable was also verified with an isolated fixture process.
